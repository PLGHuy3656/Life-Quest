# Life-Quest
Đồ án thực tế công nghệ phần mềm - Hệ thống quản lý mục tiêu cá nhân theo phong cách Gamification / RPG.

## Cấu trúc dự án
- **`backend/`**: RESTful API sử dụng Node.js (ES Module), Express 5, Prisma v7 ORM và cơ sở dữ liệu PostgreSQL.
- **`front-end/`**: Ứng dụng web cơ bản (React 18 + Vite).
- **`mobile/`**: Ứng dụng Mobile UI (React 18 + Vite) thiết kế theo phong cách Cyber-Fantasy RPG, tích hợp đầy đủ hệ thống Quests, EXP, Level Up, Streak và kết nối với Backend API.

## Hướng dẫn khởi chạy Mobile UI
```bash
cd mobile
npm run dev
```
Truy cập `http://localhost:5173` và bật chế độ hiển thị Mobile (F12 -> Ctrl + Shift + M) trên trình duyệt để trải nghiệm.
