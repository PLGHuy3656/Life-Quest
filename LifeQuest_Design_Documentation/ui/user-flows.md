# User Flows

## New User

``` text
Landing
 -> Register
 -> Login
 -> Profile Setup
 -> Create Goal
 -> AI Goal Plan (optional)
 -> Review Plan
 -> Start Quest
```

## Daily Flow

``` text
Dashboard
 -> Daily Quest
 -> Complete Quest
 -> XP/Level update
 -> Analytics update
 -> Social post (optional)
```

## Habit Flow

``` text
Habit List
 -> Select Habit
 -> Check-in
 -> Streak update
 -> Gamification update
```

## Social Flow

``` text
Feed
 -> View Post
 -> React / Comment
 -> Friend interaction
```

## Challenge Flow

``` text
Challenge List
 -> Challenge Detail
 -> Join
 -> Progress
 -> Leaderboard
```
