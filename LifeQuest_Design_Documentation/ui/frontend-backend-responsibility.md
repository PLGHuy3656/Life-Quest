# Frontend vs Backend Responsibility

## Frontend

-   Render UI
-   Local UI state
-   Form state
-   Loading/error presentation
-   Optimistic UI only when safe
-   Route/navigation
-   Token storage strategy theo security policy

## Backend

-   Validation
-   Authorization
-   Business rules
-   Data integrity
-   Transaction
-   XP/coin calculation
-   Streak calculation
-   Event publishing
-   AI integration

## Rule

Frontend không tự quyết định: - XP được cộng bao nhiêu - User có được
sửa resource hay không - Streak có hợp lệ hay không - Achievement đã
unlock hay chưa
