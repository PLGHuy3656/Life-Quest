# Functional Requirements

## 1. Identity & Account

-   Đăng ký
-   Đăng nhập
-   Refresh token
-   Đăng xuất
-   Quên mật khẩu
-   Đổi mật khẩu
-   Xem/cập nhật profile
-   Quản lý user settings

## 2. Goal & Quest

-   Tạo/cập nhật/xóa goal
-   Quản lý milestone
-   Tạo/cập nhật/xóa quest
-   Gán quest vào goal/milestone
-   Lập lịch quest
-   Daily Quest
-   Hoàn thành quest
-   Quest proof

## 3. Habit

-   CRUD habit
-   Check-in habit
-   Xem lịch sử
-   Tính streak
-   Theo dõi consistency

## 4. Focus

-   Tạo focus session
-   Start/pause/resume
-   Ghi nhận interruption
-   Complete focus session

## 5. Social

-   Friend request
-   Accept/reject/remove friend
-   Post
-   Reaction
-   Comment
-   Feed theo quyền riêng tư

## 6. Challenge

-   Tạo/join challenge
-   Theo dõi progress
-   Leaderboard
-   Duo/Group streak

## 7. Gamification

-   XP
-   Level
-   Coin
-   Achievement
-   Title
-   Item/inventory
-   Mascot

## 8. Analytics

-   Overview
-   Goal statistics
-   Habit statistics
-   Focus statistics
-   Consistency
-   Activity
-   Behavior patterns

## 9. AI

-   AI Goal Planning
-   AI Behavior Analysis
-   Adaptive Recommendations

## 10. Admin

-   Quản lý user
-   Quản lý reports
-   Quản lý achievements/rewards
-   Quản lý system configuration
