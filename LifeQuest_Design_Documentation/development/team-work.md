# Team Work Contract

## Backend team

Mỗi endpoint cần hoàn thành: - Route - Validator - Controller -
Service - Repository - Migration - Test - API documentation

## Frontend team

Có thể bắt đầu ngay khi có: - endpoint - HTTP method - request schema -
response schema - status codes - error codes - enum - pagination -
loading/empty/error behavior

## Integration rule

Không tự ý đổi response field.

Nếu cần thay đổi: 1. Update API document. 2. Thông báo frontend. 3.
Update backend. 4. Update mock/test.
