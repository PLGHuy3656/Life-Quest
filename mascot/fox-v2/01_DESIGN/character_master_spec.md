## 1. Character

A small, cute, rounded chibi fox: the LifeQuest companion. One master model;
every level uses the same model at a different **uniform scale** (no age
morphs, no proportion changes). Real-time web target (glTF/Three.js later).

Design rules: cute · minimal · rounded · expressive · readable · animation
friendly. Never: realistic fur, fingers, wrinkles, new markings, costumes.

## 2. Coordinate system and units

* Blender Z-up, metres, character faces **−Y**, +X = character's left.
* Ground at Z = 0; total height 1.00 m at level-20 scale 1.00.
* glTF export (Gate F) converts to Y-up, facing +Z.

## 3. Construction (Gate B)

All geometry is generated by `08_VALIDATION/scripts/build_modules.py` from the
values in `proportions.json` / `materials.json` — no hand-sculpted state, so
every change is a code/data diff and the build is reproducible.

| Module | File | Objects | Construction |
|---|---|---|---|
| 01 Head | `02_MODEL/modules/head.blend` | `FOX_Head`, `FOX_Tuft` | vertical loft through the measured width/depth profile + cheek-fluff ridge + soft muzzle bulge; cream mask cut **exactly** along the measured ellipse (mesh is split on the boundary, no stair-steps); 3-lobe tuft swept along curves |
| 02 Face | `face.blend` | eyes, blush, nose, 3 mouths, 2 closed-eye sets, brows | thin shells projected onto the subdivided head surface (0.3–12 mm clearance, validated) |
| 03 Ears | `ears.blend` | `FOX_Ear_L/R` + `FOX_EarInner_L/R` (child) | U-bowl loft with rounded rim lip, dome tip and broad upper half, cream lining shell inside the bowl; pivot at ear base for rotation |
| 04 Body | `body.blend` | `FOX_Body` | pear loft, cream belly cut along measured ellipse |
| 05 Limbs | `arms_legs.blend` | `FOX_Arm_L/R`, `FOX_Leg_L/R` | swept arms with rounded paws (brown on lower 42 %), lofted legs with forward-reaching brown feet; pivots at shoulder / hip |
| 06 Tail | `tail.blend` | `FOX_Tail` | teardrop sweep along a 7-point spine (ready for TAIL_01–03 chain): curling toward the character's right (−X), slim base behind the backpack; zig-zag cream tip cut exactly along a 5-tooth wave |
| 07 Scarf | `scarf.blend` | roll, flap, emblem | bunched torus roll + bandana triangle projected onto chest (solidified) + flame emblem with inner red flame |
| 08 Backpack | `backpack.blend` | pack, flap, buckle, pockets, 2 straps | rounded boxes + swept straps snapped to the torso; whole hierarchy parented to `FOX_Backpack` → detachable |

Master: `02_MODEL/fox_master.blend` appends the eight `GEO_*` collections:

```
FOX_MASTER
├── GEO_HEAD  GEO_FACE  GEO_EARS  GEO_BODY  GEO_LIMBS  GEO_TAIL  GEO_SCARF  GEO_BACKPACK
├── RIG             (empty until Gate D)
├── ATTACHMENTS     (empty until Gate D)
└── LIGHTING_PREVIEW (5 soft area lights, rotated with the review camera; camera/ground added at render time)
FOX_ROOT (empty) — parent of every top-level mesh; uniform level scale goes here
```

Subdivision modifiers are kept live (viewport 1–2 / render 2) so the source
stays light and editable; they are applied at glTF export.

## 4. Facial control architecture (prepared, not yet rigged)

Kept deliberately simple and web-friendly:

| Expression | Eyes | Mouth | Brows |
|---|---|---|---|
| Neutral | open | ω (Neutral) | hidden |
| Blink | shape key `Blink` 0→1 | — | — |
| Happy | swap → `EyeClosedHappy` (^ ^) | `Mouth_Open` + tongue | hidden |
| Proud | shape key `Proud` (level half-lid) | `Mouth_Smile` (wide ω, lifted corners) | key `Proud` (raised soft arch) |
| Sad | shape key `Sad` (lid slopes down to outer corner) | `Mouth_Frown` | key `Sad` (inner ends lifted) |
| Surprised | shape key `Wide` | `Mouth_Open` | hidden |
| Sleepy | swap → `EyeClosedSleepy` | `Mouth_SmallO` | hidden |

`HalfLid` shape key is available for drowsy blends. Proof render:
`01_DESIGN/comparisons/fox_face_controls_r4.png`.

## 5. Materials

Ten Principled-BSDF materials, no textures (see `materials.json`). Palette hex
values are used as base colours; review renders use the *Standard* view
transform with −0.7 EV exposure; the light rig rotates with the camera so all views share the same lighting.

## 6. Level scale (for later gates)

| Level | 1 | 5 | 10 | 20 | 30+ |
|---|---|---|---|---|---|
| Scale | 0.80 | 0.86 | 0.92 | 1.00 | 1.10 |

Applied to `FOX_ROOT` only (body, tail, scarf, backpack and future attachments
scale together). Stored in the scene property `fox_level_scale_map`.
